# NexTraff AI
### An AI-Powered Traffic Monitoring and Congestion Analysis System

## Project Overview
NexTraff AI is a web-based AI-powered traffic monitoring system designed to detect and count vehicles from uploaded traffic videos and estimate traffic congestion levels.

## Problem Statement
Traffic congestion is a common problem that causes delays, fuel wastage, and difficulties in traffic management. Manual traffic monitoring can be time-consuming and inefficient. NexTraff AI aims to make traffic monitoring easier through AI-based vehicle detection and congestion analysis.

## Objectives
- Detect vehicles from uploaded traffic videos.
- Count detected vehicles.
- Estimate traffic congestion levels.
- Display analysis results through a dashboard.
- Store previous analysis results for future reference.

## Proposed Features
- Traffic video upload.
- AI-based vehicle detection.
- Vehicle counting.
- Traffic congestion estimation (Low, Medium, High).
- Dashboard for displaying analysis results.
- Previous analysis history.

## Proposed Technology Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **AI Model:** Python, YOLO
- **Version Control:** Git and GitHub

## Project Scope
The system will analyze uploaded traffic videos. Real-time traffic monitoring and traffic signal control are outside the initial project scope.
